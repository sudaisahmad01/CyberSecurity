# 🛡️ Cyber Security & Digital Safety Awareness Website

An educational, multi-page web project designed to spread awareness about digital security, modern cyber threats, protection practices, and future trends in technology.

---

## 🚀 Features

- **🌐 Multi-Page Architecture**: Structured pages including Home, Cyber Threats, Protection Guide, Future Trends, and Contact Us.
- **📱 Responsive Layout**: Styled with custom CSS to ensure a seamless view across devices (Desktops, Tablets, and Mobile phones).
- **🔒 Cyber Security Knowledge Base**:
  - Detailed explanations of common cyber threats (Malware, Phishing, Ransomware, etc.).
  - Actionable security protection checklists & safe browsing tips.
  - Insights into AI, Cloud Security, IoT, and Quantum Computing trends.
- **✉️ Interactive Contact Form**: A clean contact section for user inquiries and feedback.
